# Concrete Master — Demo Website

Demo site built by Wilson Innovations for **Concrete Master** (Instagram: @concretemaster_usa),
a concrete polishing and resinous flooring contractor serving South Florida.

- **Live demo:** https://wilsonramstead.github.io/concrete-master/
- **Phone:** (954) 839-5151 (tel: + sms: CTAs)
- **Services shown (from their ad):** concrete polishing, epoxy floors, metallic epoxy,
  flake systems, quartz, self-leveling — industrial / commercial / residential.

## Design

- **Fonts:** Fjord One (display, Google Fonts) + Ranade (body, Fontshare)
- **Palette:** polished-concrete neutrals — ink `#17171a`, graphite `#232327`,
  concrete `#e9e8e4`, fog `#f6f5f1` — with a molten copper accent
  (`#d98d52 → #b56a35 → #7e441d` gradient) echoing metallic epoxy.
- **Spine:** the six floor finishes as a portfolio menu (metallic epoxy featured as the
  signature card) + a three-segment band (industrial / commercial / residential).
